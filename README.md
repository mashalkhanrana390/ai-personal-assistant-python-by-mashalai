# 🤖 AI Personal Assistant

A simple **AI Personal Assistant built with Python**.
This beginner-friendly project can understand basic commands and provide the current time, date, greetings, and other responses.

## ✨ Features

* 👋 Hello greeting
* 😊 "How are you?" response
* 🤖 Assistant name response
* 🕐 Current time
* 📅 Current date
* ❌ Unknown command handling
* 🚪 Exit command
* 🔄 Continuous command loop

## 🛠️ Technologies Used

* Python 3
* `datetime` module
* Functions
* Conditional statements
* `while` loop
* User input
* String methods
* F-strings

## 📚 Python Concepts Practiced

This project uses:

* `def` — creating functions
* `input()` — taking user input
* `print()` — displaying output
* `.lower()` — converting text to lowercase
* `.strip()` — removing extra spaces
* `datetime.now()` — getting current date and time
* `.strftime()` — formatting date and time
* `if / elif / else` — decision making
* `while True` — continuous execution
* `break` — stopping the loop
* `return` — returning a response
* `f-string` — inserting values into text

## ▶️ How to Run

Make sure Python is installed.

Run the program:

```bash
python main.py
```

```text
==============================
```
